# Historical repository material

Everything under `legacy/` is recoverable history, not an active product or
operational input.

- `retired-generated-frontend/` preserves the superseded generated frontend.
- `menu-import-history/` preserves the pre-admin import and fixture toolchain.
- `summer-pause/` preserves the retired Summer Pause campaign intact.

Do not include these trees in builds, releases, deployments, provisioning, or
menu workflows. See `../GOVERNANCE.md` for the ownership model and the rules for
any deliberate restoration.
