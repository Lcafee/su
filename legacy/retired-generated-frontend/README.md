# Retired generated frontend

These files are preserved only as migration history. They are not inputs to
Vite, are not copied to `dist/`, and must not be maintained in parallel with
the React application.

The active frontend source of truth is `src/` and the root Vite HTML entries.
The older design-canvas documents, Python HTML generator, custom-element
runtime, and hand-ported shader are recoverable here if historical comparison
is ever needed. Their former `menu.json` input is preserved separately under
`legacy/menu-import-history/`; neither location is operational.
