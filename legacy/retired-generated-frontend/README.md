# Retired generated frontend

These files are preserved only as migration history. They are not inputs to
Vite, are not copied to `dist/`, and must not be maintained in parallel with
the React application.

The active frontend source of truth is `src/`, the two root Vite HTML entry
files, and `menu.json`. The older design-canvas documents, Python HTML
generator, custom-element runtime, and hand-ported shader are recoverable here
if historical comparison is ever needed.
