# Legacy menu import history

This directory preserves the pre-admin `menu.json`, its generated Excel view,
the retired image/fixture generators, and the one-time PHP import implementation
that initialized the managed menu system. Production was imported before
2026-08-29 and now uses MySQL plus `managed-menu/` and `managed-media/`.

Nothing here is an active build, release, provisioning, deployment, or menu
editing input. The archived scripts retain their historical paths and may not
run from this directory without reconstruction; do not repair or invoke them as
an operational workflow. New menu content is created and published through the
authenticated admin.
