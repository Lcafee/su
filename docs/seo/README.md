# SEO planning

This directory contains the SEO-only research, measurement plan, backlog, and
roadmap. These files do not define general project state, product priority, or
release authorization.

- `ROADMAP.md` — staged SEO sequence and lock gate.
- `BACKLOG.md` — evidence-backed SEO work candidates.
- `RESEARCH.md` — SEO research and limitations.
- `MEASUREMENT.md` — SEO measurement definitions and baseline protocol.

Current project phase, blockers, source baseline, and next authorized action
remain authoritative only in `../../PROJECT_STATE.md`.
