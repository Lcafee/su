# ال کافه — L Cafe

Landing page and menu for L Cafe, Esfahan. Persian / RTL, fully static.

## Pages

| Source (design canvas) | Published |
| --- | --- |
| `Landing Hero Background.dc.html` | `index.html` |
| `Menu.dc.html` | `menu.html` |

`Landing Background Options.dc.html` is a design-exploration document, not part
of the site.

## Editing

The `.dc.html` files are the source of truth — they are what the design-canvas
tool reads and writes. `support.js` and `image-slot.js` are generated by that
tool; don't hand-edit them.

After editing a page, regenerate the published files:

```
py build.py
```

Then commit and push. GitHub Pages serves this repository's root, so the
generated `index.html` / `menu.html` go live directly.

## Dependencies

None at runtime. React and Babel are vendored under `assets/vendor/` and the
runtime is pointed at them via `window.__resources`, so the pages render with
no CDN and no network beyond this origin. Fonts (Vazirmatn, Sahel Bold — OFL)
are self-hosted under `assets/fonts/`.
